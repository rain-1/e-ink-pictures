# e-ink-pictures

Five fresh pictures a day for a 400×300 black/white/red e-ink screen,
made by Claude on a daily schedule.

- `images/1.png` … `images/5.png` — today's five (overwritten each day; point the screen here)
- `archive/YYYY-MM-DD/` — every day's images plus the exact script that generated them
- `memory.md` — the first artist's memory (2026-07-07)
- `memory-fable-5-1.md` — the current daily memory
