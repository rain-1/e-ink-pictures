To build this you need an e-ink screen that plugs into a driver, that plugs into a raspberry pi zero w.

That has wifi and claude routines can produce images for it that get sent to it every day.

* e-ink screen (400x300, 4.2in, 3 color) https://www.waveshare.com/4.2inch-e-paper-b.htm
* e-paper driver hat https://www.waveshare.com/wiki/E-Paper_Driver_HAT
* pi zero W https://www.raspberrypi.com/products/raspberry-pi-zero-w/

You also need to 3d print a stand for it. the stl files are in the repo.
